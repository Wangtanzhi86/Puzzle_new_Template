# 结束界面卡片图改 SizeMode = TRIMMED（等比，不再横向拉扁）（2026-10-20）

## 改了什么

- `End/Carousel/Card_01..10/Clip/Image`：`Sprite.sizeMode` 由 `CUSTOM`（硬拉到 240×400）改为 `TRIMMED`。
- 因为 TRIMMED 会把节点尺寸换成图片原尺寸（第 1/2/3/5 集 482×594，第 6/8/9/10/11/12 集 928×1152），
  再按「等比铺满」缩回卡片框：`k = max(卡片宽/图宽, 卡片高/图高)`，节点回 `(0,0)` 居中，由 `Clip` 那层圆角遮罩裁边。
  实测 k：482×594 → 0.673（显示 325×400）；928×1152 → 0.347（显示 322×400）。
- 生成器 [mount-end-carousel.js](tools/js/mount-end-carousel.js) 同步改了（以后重跑生成的也是 TRIMMED + 等比），
  另加一个幂等修补脚本 [fix-end-card-trim.js](tools/js/fix-end-card-trim.js)。

## 为什么这么改

原先是 `CUSTOM` + 节点直接设成 240×400，图片被非等比拉伸（人物脸变宽）。
只改成 TRIMMED 不够：TRIMMED 保持原图像素尺寸，928×1152 的图会撑出卡片框 4 倍多，
只剩正中间一小块可见 —— 所以补一步等比缩放到「铺满卡片框」，多余部分交给已有的圆角 Mask 裁掉。

## 怎么验的

- 脚本回读：10 张卡全部 `sizeMode=TRIMMED`，缩放与显示尺寸见上（都恰好 400 高）。
- 存盘后核对 `assets/scene.scene`：`_sizeMode: 1` 已写入文件（mtime 14:44）。
- 按约定没有跑预览截图。

## 影响什么 + 还没验的部分

- 图片不再变形，但**四周会被裁掉一部分**（铺满的代价）。若要「整图完整可见」，把 `k` 换成 `min(...)` 即可（会留出上下或左右的黑边）。
- 没验：不同集图裁切后主体是否还在画面中（尤其 928×1152 那几张，左右各裁掉约 1/3）。
