# 女主换人改到槽位 3 修复动画播完之后

- 日期：2026-10-21
- 提交：<提交后回填>
- 关联：AGENTS.md §5 / docs/changes/2026-10-21-槽位1常驻.md

## 改了什么

- `gameplay/SlotSwap.ts` 新增开关 `waitShown`（「等揭晓播完再切」）：勾上后不再在
  `PIECE_REPAIRED`（吸附成功）时切，而是等 `PIECE_SHOWN`（这一格修复动画整段演完）再切；
  `delay` 改成从露面那一刻起算。默认 false，其余 SlotSwap 实例行为不变。
- 场景 `Canvas/GameLayer/Scene_BG` 上盯 `Slot_03` 的那个 SlotSwap：`waitShown = true`、`delay` 0.2 → 0，
  即 `女主动作1` → `女主动作二` 在槽位 3 的金色烟花 + 圆形扩散整段演完后立刻换。
- `tools/js/mount-slot-swaps.js` 同步（roleSwap 加 `waitShown`、delay 归 0），重跑接线脚本不会退回旧时机。

## 为什么这么改

- 原来挂在 `PIECE_REPAIRED` 上，那一刻只是吸附成功，槽位 3 的烟花（0.24s 提前量）和圆形扩散还没开始，
  人物在修复动画之前就换了，观感上「人先变、图后修」。
- 否掉的方案：把 delay 从 0.2 调大到动画时长。动画时长随揭晓方式和参数变（烟花 / 扩散 / 序列帧），
  写死秒数迟早对不上；`PIECE_SHOWN` 本来就是项目里「这一格演完了」的权威信号（`SceneBgSwap`、
  `RepairSweep`、`EndgameCta` 都按它算），直接复用。

## 怎么验的

- `assets/scene.scene` JSON 校验通过；场景里该实例现为 `"waitShown": true, "delay": 0`。
- 没有跑编辑器预览（本轮编辑器未开，MCP 不在线），也未做 TS 编译（本地无 tsc，靠编辑器编译）。

## 影响什么 / 还没验的部分

- 只影响勾了 `waitShown` 的实例；槽位 2 换图、开场露紧张表情两个 SlotSwap 不变。
- 待验：编辑器打开后需刷新资源库（`.ts` 新增 `@property`），确认 Inspector 里出现「等揭晓播完再切」并已勾选；
  预览确认槽位 3 烟花扩散演完的同一拍换人，且换人不再早于修复图出现。
