# 开局：每格白色描边以自己中心为原点 360° 扫出

- 日期：2026-10-20
- 提交：616f342
- 关联：AGENTS.md §15 / docs/TUNING.md 开局描边转出行

## 改了什么

- 新增 `assets/effects/radial-sweep.effect`：按世界坐标角度做 alpha 遮罩。参数 `sweepParams = (圆心x, 圆心y, 已扫圈数, 羽化比例)`，从正上方起顺时针扫。
- 新增 `assets/scripts/gameplay/RadialSweep.ts`：`LEVEL_BUILT` 时给每个非预填槽位的 `Broken` 挂材质并把进度压到 0；`GAME_START` 后按 `delay + stagger` 逐格扫出，扫完还原 `customMaterial` 并销毁材质。
- `config/FeatureFlags.ts` 新增 `radialSweep`（默认开）。关掉 = 不挂材质，描边直接显示。
- `assets/scene.scene`：`EffectLayer` 挂 `RadialSweep`（`sweepEffect` 指向新 effect，`sweepTime=1.2`、`stagger=0.15`、`delay=0`、`feather=0.06`），Canvas 开关置 true。
- `tools/js/mount-radial-sweep.js` 幂等接线；`tools/js/verify-scene.js` 增加存在性与 `sweepEffect` 检查。
- 文档：AGENTS.md §15、docs/ARCH.md、docs/TUNING.md。

## 为什么这么改

- 按原话把「白色描边本身」当作扫出的内容：材质只做角向 alpha 遮罩，不另铺一层彩色图。若本意是「扫开描边露出底下的彩色图」，只需换挂载对象 / 加一层被裁的彩色图，角度遮罩可复用。
- 用世界坐标算角度，而不是节点 UV：非正方形槽位的 UV 会把扇形压扁。
- 预填槽位（Slot_01）跳过：它由 `PrefillFlight` 飞入 + 金色烟花接管，再扫描边会打架。
- 挂在 `EffectLayer` 而不是逐格挂组件：一份组件听 `LEVEL_BUILT` 拿槽位表，参数集中，符合「能调的数在 Inspector」。
- 否掉「用 Mask 组件做扇形」：Mask 是 2D 裁剪、逐帧改顶点代价高，且与已有 RECT Mask 叠加易出问题；材质一行 alpha 就够。

## 影响什么 / 还没验的部分

- 只影响开局非预填槽位的 Broken 显示时机；不碰吸附、修复、进度、埋点。
- 实际观感（扫速、错开、羽化宽度、白色描边的 alpha 是否够）需要预览确认。
- 若槽位 Broken 图本身不是白色描边，而是彩色破损图，现在会「转出彩色图」；要改成「先白描边再露彩色」需要另加一层。
