# 结束界面扫光：Logo / 按钮 / 正中卡片错时扫（2026-10-20）

## 改了什么

- 新增 [EndSweep.ts](assets/scripts/ui/EndSweep.ts)，挂在 `End` 上。每轮依次扫三个目标，默认：
  Logo `0.1s` → 按钮 `0.7s` → 正中卡片 `1.45s`（卡片带进场快滚约 1.1s，别扫在飞的那一下），
  单次 `0.7s`、光带半宽 `0.22`、整图补光 `0.14`，一轮结束隔 `repeatGap 2.2s` 再来一轮（填 0 = 只扫一轮）。
- 复用现成的 [repair-sweep.effect](assets/effects/repair-sweep.effect)（和修复扫光同一支 shader）：
  sweep 节点是目标的子节点、同尺寸同 spriteFrame，所以**贴图 alpha 天然当裁剪** ——
  圆形徽标、圆角卡片（挂在 `Clip/Image` 上，再被 `RoundedClip` 裁一次）、带透明边的 Logo 都不会扫出方光块。
- [EndCarousel.ts](assets/scripts/ui/EndCarousel.ts) 加 `get centerItem()`，供扫光取「此刻正中那张」。
- 接线脚本 [mount-end-sweep.js](tools/js/mount-end-sweep.js)；已存盘。

## 为什么这么改

光带几何在 shader 里按**世界坐标**投影，所以每个目标得各自算一条自己的扫描轴（45°，左下→右上）；
三者尺寸差很大（Logo 631×267、按钮 692×209、卡片 240×400），共用一条轴就会有的扫不满、有的还在框外。
错时的用意：三样同时亮会像整屏闪一下，错开 0.6s 才读得出「光从上面走下来」。

否掉的方案：自己写一个新 effect（没必要，repair-sweep 的坐标约定正好可直接复用）；
给三个目标各挂一个 EndSweep 组件（时序要跨节点对齐，反而更绕）。

## 怎么验的

- TS 诊断 `no errors`；`npm run check` `ok: true`。
- 场景回读：`EndSweep.sweepEffect` 指向 repair-sweep、`logo=文字标题`、`button=btn`、`carousel` 已接、延迟 0.1/0.7/1.45、`repeatGap 2.2`。
- 按约定没有跑预览。

## 影响什么 + 还没验的部分

- 每次扫光会临时建一个 Sprite 子节点 + 一份 Material，扫完销毁；每轮 3 份，循环播放时不残留。
- 没验：① 光带强度和宽度（`band 0.22 / flash 0.14 / 颜色 alpha 190`）；② 在真机上循环扫会不会太频繁（把 `repeatGap` 提到 3.5 或直接填 0）；
  ③ 卡片是「当前正中那张」，若在扫的 0.7s 内正好步进换卡，光会跟着那张旧卡走完 —— 需要的话可以在 `sweep` 里锁节点不重取。
