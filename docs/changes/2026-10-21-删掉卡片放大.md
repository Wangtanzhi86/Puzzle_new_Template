# 删掉点关时的关卡图片放大 / 残影 / 缩放模糊

- 日期：2026-10-21
- 提交：<待回填>
- 关联：docs/VIDEO.md「开头视频（选关之后）」/ AGENTS.md §18

## 改了什么

- `assets/scripts/ui/GameIntro.ts` 重写：点关（`LEVEL_SELECTED`）后直接调 `EndVideo.play()` 起播
  `IntroLayer/开头视频`；没配视频 / `skip` 勾上 / 起播失败就当场 `finish()`。
  删掉 `select / region / flyTime / zoomTime / cornerRadius / cornerFade / readyTimeout /
  blurEffect / ghostCount / ghostOpacity / ghostLag / blurMax` 与整套卡片放大、残影、圆角收边、模糊驱动。
- `assets/scripts/platform/EndVideo.ts` 删掉只为「静图交接视频」而生的 `playCovered()` / `reveal()` /
  `_covered` / `_ready` / `markReady`；`play()` 起播即亮画面。
- 删除 `assets/scripts/ui/IntroMotionBlur.ts(.meta)` 与 `assets/ReusableDragFx/zoom-blur.effect(.meta)`。
- 场景 `assets/scene.scene` 存盘一次，序列化里不再带上述字段；`GameIntro.video` 仍指
  `Canvas/IntroLayer/开头视频` 的 `EndVideo`，`skip = false`。
- `tools/js/mount-intro-video.js` 去掉 `intro.region` 回填与返回值里的 region。
- `docs/VIDEO.md`、`docs/STATUS.md` 改成「点关直接起播视频」；上一份
  `docs/changes/2026-10-21-开头视频.md` 顶部加注「放大段描述已过时」。

## 为什么这么改

- 老板明确要求「点击关卡将关卡图片模糊放大的逻辑删掉」：这张放大图只是视频前的过渡，
  现在直接起播更短、更少一层 DOM/节点，也少一套要调的残影与材质。
- 选择**连代码和 effect 一起删**，而不是留成不挂载的死代码：web-mobile 产物不做跨模块死代码消除，
  留着就照旧进包；`zoom-blur.effect` 也不再被任何地方引用。
- 否掉的方案：① 只把 `skip` 勾上 —— 代码还在，下次容易又打开；② 保留 `IntroMotionBlur` 只删调用 ——
  脚本和 effect 仍占体积；③ 保留卡片静帧、直接淡入视频 —— 老板要的是删掉放大逻辑，不是换过渡。

## 怎么验的

- `grep` 全 `assets/`：除被删文件自身外，已无 `IntroMotionBlur` / `zoom-blur` / `blurEffect` 引用；
  `assets/scene.scene` 里也没有 `63c6f8bb-…` 这个 effect uuid。
- 通过 MCP 读回 `Canvas/IntroLayer` 的 `GameIntro`：只剩 `video` / `skip` 两个业务字段，
  `video.node.name = "开头视频"`、`skip = false`；场景已存盘（UUID `bdd769ed-06ed-4ddc-86e0-54318ac1aeba`）。
- 改了 `.ts` 后跑 `node tools/exec.mjs editor tools/js/refresh.js`；`temp/.../chunks/e8/e8d0b4d9…js`
  里已出现新字段 `跳过开场视频`，说明编辑器按新类重编了。
- `tsc --noEmit` 零报错；`npm run check` 通过（只剩原有的 `ProgressController.label` 为空告警）。
- 按老板偏好没有跑预览 / 截图，未做视觉自证。

## 影响什么 / 还没验的部分

- 点关后不再有关卡图放大的过渡，直接出视频；选关界面到视频之间会是一次直切，观感待实机确认。
- 视频仍是全屏 cover：720×404 片源在 720×1280 下左右各裁约 34%，这个构图问题没变。
- `GameIntro.skip` 保留：勾上仍可点关直接进游戏（照常发 `GUIDE_RESUME` + `GAME_START`）。
- 未跑预览；`refresh_assets` 后旧预览需重开才会用新 chunk。
