# 换节点来回交叉淡入（2026-10-21）

- 日期：2026-10-21
- 提交：待提交
- 关联：AGENTS.md §15 / §16

## 改了什么

- `assets/scripts/config/FeatureFlags.ts` 新增开关 `swapAlternate`（默认 true，显示名「换节点来回交叉淡入」）。
- `assets/scripts/gameplay/SlotSwap.ts` 新增三个 Inspector 参数：`alternateFlips = 4`（来回切换次数）、`alternateFirst = 0.1`（第一次切换时长）、`alternateGrow = 1.5`（每次变慢倍率）。
- 开关打开且 `hideNodes` / `showNodes` 都不为空时，切换改为：新→旧→新→旧→新……每拍时长按 `alternateGrow` 递增，最后一拍固定到新节点；结束时才把旧节点 `active = false`，并按 `pop` 给新节点一个轻微放大回弹。开关关掉或 `fadeTime <= 0` 时保持原来的一次交叉淡入 / 硬切。
- 场景 `assets/scene.scene` 上 `Scene_BG` 的两个 `SlotSwap` 已序列化新字段（4 / 0.1 / 1.5），Canvas 的 `FeatureFlags.swapAlternate` 为 true。
- 文档：`AGENTS.md` §15 开关表加一行；`docs/TUNING.md` 加 `alternateFlips / alternateFirst / alternateGrow` 调参行。

## 为什么这么改

- 需求是「女主换表情、小三换动作时来回切换，频率变慢再固定」，最直接的落点是已有的 `SlotSwap`：它本来就负责这两处换节点，且只碰 `active / UIOpacity / scale`，不需要改事件、槽位或美术。
- 没有把节奏写死在代码里：次数、起手时长、变慢倍率都放到 Inspector，方便实机调手感；总开关放 `FeatureFlags`，关掉就退回原表现。
- 否掉的方案：在 `PieceSlot.repair()` 里另写一套换人逻辑 —— 会把换节点职责拆成两处，且 Slot_02 / Slot_03 的 `hideOnRepair`、`swapHide/swapShow` 已经各有分支，容易互相打架。
- 否掉的方案：用 `Tween` 的 `repeat` 做往返 —— 每次时长不能递增，做不到「频率变慢」。

## 影响什么 / 还没验的部分

- 只影响 `SlotSwap` 的换节点表现；不改变事件、进度、吸附判定或终局流程。
- 默认节奏总时长约 1.16 秒（4 拍：0.1 / 0.15 / 0.225 / 0.3375，最后 0.35 秒落定）；如果实机觉得拖沓，优先降 `alternateFlips` 或 `alternateFirst`。
- 开关关掉后只做一次普通交叉淡入，行为和改动前一致；`fadeTime = 0` 仍走硬切。
- 两个 `SlotSwap` 的 `delay` 仍是 0.25 / 0.2 秒，来回段从延迟结束后才开始；实际观感待预览确认。
