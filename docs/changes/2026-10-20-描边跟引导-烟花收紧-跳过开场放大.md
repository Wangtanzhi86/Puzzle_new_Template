# 描边跟引导 + 金色烟花收紧 + 跳过选关放大

## 改了什么

- `assets/scripts/core/GameEvent.ts` 新增 `GUIDE_PIECE`（载荷 `slotIndex`）。
- `assets/scripts/ui/GuideController.ts` 每一遍引导 `next()` 指到某格时发 `GUIDE_PIECE`，不改引导自己的节奏。
- `assets/scripts/gameplay/RadialSweep.ts` 不再在 `GAME_START` 后一起扫：建关仍给非预填槽位挂材质、进度封在 0，收到 `GUIDE_PIECE` 才把那一格的白色描边转出来；`_introduced` 保证每格只演一次。`FeatureFlags.guide` 关掉时退回原来的开场逐格扫。
- `assets/scripts/gameplay/FireworkReveal.ts` 默认 `burstLead` 0.18→0.24、`burstTime` 0.12→0.16。
- `assets/scene.scene`：`FireworkReveal.revealTime` 0.6→0.8；`GoldenBurst` 粒子收小收慢（56 粒、360/s、寿命 1.1±0.2、尺寸 26±7、重力 -160、初速 150±50、径向 -50、散布 4×4）。
- `assets/scripts/ui/GameIntro.ts` 新增 `skip`；勾上时 `onLevelSelected` 隔一帧直接 `finish()`（保留 `GAME_START`），不演卡片放大铺满。场景已置 `skip = true`。
- 文档同步：`AGENTS.md` 事件表 / §15 开关说明、`docs/ARCH.md`、`docs/TUNING.md`、`docs/STATUS.md`、`docs/VIDEO.md`。

## 为什么这么改

- 描边如果开场全亮，引导指过来时没有「这一格才被介绍」的感觉；改成由引导触发，视线跟着手指走。材质仍在建关时挂上并把进度封 0，避免引导第一次指到时才加载材质闪一下。
- 烟花原来粒子多、初速高、重力大，炸得又散又快；这次减数量、降初速、减重力、延长寿命，同时把圆形扩散本身放慢到 0.8s，让「炸开 → 扩散」两拍连得上。
- 选关放大这段当前不需要，但保留 `GameIntro` 的放大代码与视频恢复路径，只加一个场景开关；没有删节点。
- 否掉「给描边单独加一层节点」：现有 `radial-sweep` 材质已经能按角向裁 alpha，另起一层会多一份节点与同步成本。

## 影响什么 + 还没验的部分

- 开局不再出现任何白色描边，直到空闲引导第一次指到某格；玩家如果一直不操作，只会看到引导那一格的描边。
- 点关后直接进游戏，开场时长缩短；`GAME_START` 仍由 `GameIntro.finish()` 发出，BGM / 常驻音起点不变。
- 场景里另有 `Slot_02` / `Slot_03` 两处 `pieceId` 对调（2↔3），是本次之前工作区已有的未提交改动，未还原，随本次一起提交；若并非本意，在编辑器里改回即可。
