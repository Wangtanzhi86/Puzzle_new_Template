# 槽位 1 改常驻，碎片缩减为 3 块

- 日期：2026-10-21
- 提交：待提交
- 关联：AGENTS.md §1 / §5 / §6 / §15

## 改了什么

- 场景：`Slot_01` 已从 `BrokenLayer` 移出，当前只剩 `Slot_02`（pieceId 1，香槟杯）、`Slot_03`（pieceId 2，渣男）、`Slot_04`（pieceId 3，男主），碎片池按 pieceId 排成这 3 块。
- 场景：`小三1动作` 开局常驻显示；`小三动作2` 改为初始隐藏；`女主动作1` 显示（其子节点 `女主紧张表情` 初始隐藏）；`女主动作二` 初始隐藏。
- 场景：`Scene_BG` 上两个 `SlotSwap` 重新接线：
  - 第一个 `watch = Slot_02`，修好时隐藏 `小三1动作`、显示 `女主紧张表情` 与 `小三动作2`（delay 0.25 / fade 0.3 / pop）。
  - 第二个 `watch = Slot_03`，修好时隐藏 `女主动作1`、显示 `女主动作二`（delay 0.2 / fade 0.35）。
- 代码：`RepairSystem` 去掉 `PREFILL_DONE` 等待，只统计非预填槽位；`ProgressController` 初始进度改为 `0 / 非预填总数`；`GuideController` 删除 `prefillDelay` 与预填等待逻辑；`GameEvent` 删除 `PREFILL_DONE`。
- 代码：`PieceSlot` 删除 `resetPrefill()` / `playPrefill()` / `prefillShown`，保留 `prefill()` 作为“开局常驻、画面直接铺成修复态、不计进度”的可选能力。
- 清理：删除 `assets/scripts/gameplay/PrefillFlight.ts`（含 .meta）、`tools/js/mount-prefill-flight.js`、临时脚本 `tools/js/apply-slot-permanent.js`；`verify-scene.js` 删除 `PrefillFlight` 检查项与 `checkPrefill`。
- 文档：`docs/ARCH.md`、`docs/TUNING.md`、`AGENTS.md` 事件表同步去掉 `PrefillFlight` / `PREFILL_DONE` / `prefillDelay`。

## 为什么这么改

- 小三改为开局常驻后，“开场自动放置”没有对象了，保留 `PrefillFlight` 只会让引导和进度继续等一个永不发生的事件。
- 否掉的方案：保留 `PrefillFlight` 但把 `prefilled` 全关。代码里仍会留一套无人使用的飞行逻辑和 `PREFILL_DONE` 分支，后续读代码容易误判，不如整段删掉。
- 用 `SlotSwap` 接两段换人，是因为它本来就是“某格修好时交叉淡入淡出换一组节点”的现成组件，不需要改发射方或新增事件。
- 两段换人按 `pieceId` 排序后的第 1、2 块接，而不是按节点名 `Slot_02` / `Slot_03` 硬编码；玩家实际拿到的顺序就是香槟杯 → 渣男 → 男主。

## 怎么验的

- 通过 MCP 读场景确认：`BrokenLayer` 只有 3 个 PieceSlot，pieceId 为 1/2/3；三个 `prefilled` 均为 false；`EffectLayer` 已无 `PrefillFlight`。
- 通过 MCP 修改并保存场景（UUID `bdd769ed-06ed-4ddc-86e0-54318ac1aeba`），再读回两个 `SlotSwap` 的 `watch` / `hideNodes` / `showNodes` 与四个动作节点的初始 `active`。
- 全仓 grep 确认 `assets/scripts` 已无 `PREFILL_DONE` / `prefillDelay` / `resetPrefill` / `playPrefill` / `PrefillFlight` 引用；`prefilled` 只作为常驻槽位的可选能力保留。
- 场景里 `EndgameCta.winCount = 0`，3 块修完走“全部修完 → 结束界面”，与当前小场景一致。
