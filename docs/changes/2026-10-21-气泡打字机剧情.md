## 改了什么

- 新增 [TypewriterLabel.ts](assets/scripts/ui/TypewriterLabel.ts)：气泡上的 Label 按 `charsPerSecond` 逐字显示，最后一个字停 `hold` 秒后回调；气泡本身用 `UIOpacity` 做 `fadeIn` / `fadeOut`，隐藏后节点 `active = false`。
- 新增 [BubbleSequence.ts](assets/scripts/ui/BubbleSequence.ts)：监听 `LEVEL_BUILT` 解析两个触发槽位的下标，监听 `PIECE_SHOWN`（这一格整段揭晓演完）后按顺序播：
  - 第一段：气泡 1 打字 → 藏起 → 气泡 2 打字 → 藏起；
  - 第二段：气泡 3 打字 → 藏起。
- 场景新增 `GameLayer/BubbleLayer`（`GameLayer` 的最后一个子节点，盖在角色之上；跟着 `GameLayer` 一起被横屏布局平移 / 缩放），下挂 `Bubble_01/02/03`：
  - 气泡框用 `assets/recourses/UI及背景/气泡框.png`（296×214）；
  - 每个气泡一个 236×150 的 `Text` Label（Arial 30 / 行高 32 / CLAMP / 自动换行 / 居中），挂 `TypewriterLabel`；
  - **文字 / 位置 / 字号一律沿用场景里已经配好的值，脚本不重写**。当前 Inspector 值：
    - 气泡 1：`How could \nyou bully her?`，本地 `(75.619, 164.584)`；
    - 气泡 2：`I didn't touch \nyou!`，本地 `(-105.778, 101.599)`；
    - 气泡 3：`I believe Lily.`，本地 `(-38.159, 213.346)`。
  - 三句都带作者显式换行，`TypewriterLabel.text` 与 `Label.string` 一致；不要在代码里改成单行或改标点。
- `BubbleLayer` 上挂 `BubbleSequence`：`firstSlot = Slot_03`、`secondSlot = Slot_04`、`delay = 0`。
- `Scene_BG` 上 watch `Slot_02` 的 `SlotSwap` 改为 `waitShown = true`、`delay = 0`：女主紧张表情等槽位 2 的修复动画整段演完（`PIECE_SHOWN`）才出现。
- `Scene_BG` 上 watch `Slot_03` 的 `SlotSwap` 改为 `waitBubble = 2`、`delay = 0`：女主动作 1 → 动作 2 改由气泡 1 淡出后的 `BUBBLE_SHOW(2)` 触发，与气泡 2 起播同帧。
- [SlotSwap.ts](assets/scripts/gameplay/SlotSwap.ts) 新增 `waitBubble` 字段：填气泡序号后忽略触发槽位 / `waitShown`，只在 `BUBBLE_SHOW` 命中该序号时切换。
- [CtaController.ts](assets/scripts/platform/CtaController.ts) 新增 `waitNodes: Node[]` + `waitGrace`（默认 0.1 秒）+ `waitPoll`（默认 0.05 秒）：`END_SHOW` 后先等 `waitGrace`，再每 `waitPoll` 秒检查这些节点是否还有 `activeInHierarchy`；三个气泡全部藏好才 `playEnd()`。
- `BubbleSequence` 改为在 `LEVEL_BUILT` 里隐藏三个气泡，并在运行时 `onEnable` 里用 `EDITOR` 判断先收一遍：编辑器里保持 `active = true` 方便摆位，运行时选关 / 开场也不会露出来。
- 音效：新增 `BUBBLE_SHOW` 事件（载荷 `1 / 2 / 3`），`BubbleSequence` 在每次气泡开始打字前抛；`AudioManager.cues` 加三条同事件、`startSlot` 分别 `1 / 2 / 3` 的条目，音源为 `气泡1.MP3 / 气泡2.MP3 / 气泡3.MP3`。
- `BubbleSequence` 在气泡 2 起播前把 `secondSlot`（`Slot_04`）的破损图收起来，气泡 2 藏好后再放回；若这格已经修好 / 预填则不再放回。走 `PieceSlot.brokenView`，不新增事件或场景引用。
- 整段气泡 1 + 气泡 2 期间发 `GUIDE_HOLD` 按住空闲引导（气泡 2 藏好后再 `GUIDE_RESUME`），避免引导在气泡期间把槽位 4 的白线扫出来；同时发 `DRAG_HOLD` 锁住拖动，气泡演完再放行。

配套接线脚本：[mount-bubbles.js](tools/js/mount-bubbles.js)（**非破坏性**：场景里已有 `BubbleLayer` 就整段跳过，绝不覆盖已配的文字 / 位置 / 方向）。

## 为什么这么改

- **不用 `UILayer` 做父节点**：场景里 `UILayer` 当前 `active = false`，挂它下面 `BubbleSequence` 连 `onEnable` 都不会走，收不到 `PIECE_SHOWN`。
- **挂在 `GameLayer` 下而不是 `Canvas` 下**：`LandscapeLayout` 横屏会把 `GameLayer` 平移并缩放，气泡作为它的子节点自动跟着走；气泡本身在拼图框内（最宽的气泡 2 左边界距框边还有 12px），不会被 `GameLayer` 的 RECT Mask 裁到。
- **气泡时序不改任何现成发射方**：沿用 `PIECE_SHOWN`（`PieceSlot` 在一格整段揭晓演完后发），和 `SlotSwap.waitShown` 同一套时序；逐字与显隐全在新组件里做。只有音效需要一个「第几句」的触发点，才按 `END_DROP` 的先例补了 `BUBBLE_SHOW`，`GameEvent` / `AudioEvent` 各一条。
- **换人绑到气泡事件，不再靠时间错开**：`BubbleSequence` 在气泡 1 完全淡出、气泡 2 起播前抛 `BUBBLE_SHOW(2)`；`SlotSwap.waitBubble = 2` 收到即开始交叉淡入，所以换人和气泡 2 出现同帧。否掉了「把 `SlotSwap.delay` 硬调到气泡 1 时长之后」—— 时长随文字长度变，硬延迟不可靠；也否掉了「在 BubbleSequence 里直接调 SlotSwap」—— 那会让两个模块互相持有引用。
- **气泡 3 的音效必须能穿过 `END_SHOW` 的停全部**：`Scene_BG` 的子节点先于 `BubbleLayer` 注册，最后一格的 `END_SHOW` 会先于 `BUBBLE_SHOW(3)` 停掉全部；所以把 `BUBBLE_SHOW` 加进 `POST_OVER`，与风铃 / `END_DROP` 同一个口子。否掉了「把气泡 3 提前到 `END_SHOW` 之前」—— 那会让第三句和换场抢同一拍，也改动了既有揭晓时序。
- **结束界面等气泡，而不是反过来**：`END_SHOW` 由 `SceneBgSwap` 在最后一格 `PIECE_SHOWN` 里发出，可能比 `BubbleSequence` 的 `PIECE_SHOWN` 回调先到；那个瞬间最后一个气泡还是藏着的，直接判会误以为「没有气泡」而当场亮结束界面。所以 `onEndShow` 先延迟 0.1 秒再判，并且只在 `waitNodes` 全部不可见时才亮。否掉了「让 BubbleSequence 直接调 CtaController」—— 同样是跨模块持有引用。
- **槽位 4 的「白线」是它的破损图本身**：`Slot_04/Broken` 用的就是 `assets/recourses/提示线稿/男主白线.png`，不是 `RadialSweep` 的描边。只藏 `secondSlot` 的 `brokenView`，气泡 2 结束就恢复；恢复前检查 `repaired` / `prefilled`，避免在修复图上重新盖回白线。否掉了「给 `BubbleSequence` 再加一个 Node 字段」—— 节点已经由 `secondSlot` 确定，多一个引用只会多一处要维护。
- **只藏节点不够，会把白线的画入动作吃掉**：`RadialSweep` 的扫入 tween 目标的是材质参数，不是节点；`brokenView` 藏起来时 tween 照样走完并 `finish()` 摘掉材质，再放出来就是一张全亮的白线。所以整段对话同时用现有的 `GUIDE_HOLD` / `GUIDE_RESUME` 按住空闲引导，让 `GUIDE_PIECE` 不在气泡期间发出；气泡 2 结束后才放行，等引导重新指到槽位 4 再从头扫。否掉了「只藏节点」和「在 `BubbleSequence` 里直接持有 `RadialSweep`」—— 前者就是这次的问题，后者违反 EventBus 约定。
- **Label 显式 CLAMP + 自动换行**：否则文字逐字变长时 Label 会改自己的尺寸，气泡内排版会跳。
