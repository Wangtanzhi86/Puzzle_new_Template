# 槽位预填 / 换图换人 与金色烟花修复特效

- 日期：2026-10-20
- 提交：cad3ef9
- 关联：AGENTS.md §6 / §15 / docs/TUNING.md

## 改了什么

- `assets/scripts/gameplay/SlotSwap.ts`（新增）：通用「修好某一格 → 交叉淡入淡出换一组节点」。`watch` 留空 = 关卡建好（`LEVEL_BUILT`）立刻演；填了槽位 = 那格 `PIECE_REPAIRED` 时演；`delay` / `fadeTime` / `pop`（1.04→1 轻放大）可调。
- `assets/scripts/gameplay/FireworkReveal.ts`（新增）：继承 `CircleReveal`，先在世界中心炸一簇金色粒子（`burst`），隔 `burstLead` 秒再走原来的圆形扩散；`FeatureFlags.fireworkReveal` 关掉时退回圆形扩散。
- `assets/scripts/level/PieceSlot.ts`：加 `preFilled`（开局已修好）与 `prefill()`；加 `fireworkReveal` 引用，`repair()` 里在 `SnapReveal` 之前优先走烟花。
- `assets/scripts/level/LevelFactory.ts`：建关时对 `preFilled` 槽位执行 `prefill()`。
- `assets/scripts/gameplay/PiecePool.ts`：摆碎片时跳过预填槽位，按实际可拖块数凑一屏。
- `assets/scripts/gameplay/RepairSystem.ts`：预填格只补一次 `REPAIR_PROGRESS`（进度从 1/4 起）；**不补发 `PIECE_REPAIRED`**，否则 `EndgameCta` 按事件数计数会提前跳商店。
- `assets/scripts/level/SceneBgSwap.ts` / `assets/scripts/audio/AudioManager.ts`：`PIECE_SHOWN` 的总数改为只数非预填槽位。
- `assets/scripts/config/FeatureFlags.ts`：新增 `fireworkReveal`（默认开）。
- 场景（`assets/scene.scene`）：`Slot_01` 勾 `preFilled`；`Slot_01` 下加 `Repaired_2`（小三动作2，与 `Repaired` 同位置同尺寸）并挂 `SlotSwap`（watch `Slot_02`，淡出 `Repaired`、淡入 `Repaired_2`）；`Scene_BG` 挂两个 `SlotSwap`（watch `Slot_03` 换女主动作；空 watch 开场淡入女主紧张表情）；`EffectLayer` 挂 `FireworkReveal` + `EffectLayer/GoldenBurst`（Particle2D 金色 additive）；四个槽位接上 `fireworkReveal`，清掉旧的 `LuggageDrop` 与四种揭晓引用。

## 为什么这么改

- 换图 / 换人不写死在游戏逻辑里，做成通用 `SlotSwap`，以后任意槽位换任意节点只用 Inspector 配。
- 预填在最源头（`PieceSlot.prefill` + `LevelFactory`）处理，池子 / 进度 / 收尾各自按 `prefilled` 扣一次，避免「开局池里还躺着第 1 块」。
- 烟花接在 `CircleReveal` 前面而不是重写：圆形扩散的材质 / 时序都现成，只需要先炸一簇粒子再调用 `super.play()`。放在 `SnapReveal` 之前，避免旧的整格接管抢先。
- 否掉的方案：让 `RepairSystem` 把预填算进 `_done` 并补发 `PIECE_REPAIRED` —— 实测会让 `EndgameCta` 在第二次真实修复时就达成 `winCount=3`，第三次（可能正是要换人的那格）还没修就跳走了，所以改成只补进度、不补修复事件。

## 怎么验的

- `npm run check`（`node tools/exec.mjs scene tools/js/verify-scene.js --no-save`）：`ok:true`；仅剩既有的 `ProgressController.label=null` 与背景九宫格 inset=0。
- 场景探针：`Slot_01` prefilled=true、`Repaired_2` 贴图/位置/尺寸正确且 inactive；四个槽位 `fireworkReveal=true`、其余揭晓引用为空；`Scene_BG` 两个 `SlotSwap` 的 watch/hide/show 与预期一致；`EndgameCta.winCount=3`。

## 影响什么 / 还没验的部分

- 未跑预览：开场预填 + 紧张表情淡入、修 `Slot_02` 换图、修 `Slot_03` 换人、四格烟花 + 圆形扩散，均待编辑器实机确认。
- `winCount=3` + 预填 1 格：实际是「剩下 3 块全修完」那一格跳商店，进度条从 1/4 起、跳到商店时显示 4/4。
- 旧 `CircleReveal` / `SnapReveal` 组件仍挂在 `EffectLayer` 上，但已没有槽位引用，无运行期作用。
- 本轮新增 / 更换的美术资源（女主动作、小三动作2、白线图等）仍处于未跟踪状态，未随本次代码提交。
