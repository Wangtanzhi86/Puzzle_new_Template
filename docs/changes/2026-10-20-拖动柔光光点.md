# 导入 ReusableDragFx：拖动改成「轮廓柔光 + 光点」，用一个开关顶掉亮边与拖尾

- 日期：2026-10-20
- 提交：（未提交）
- 关联：AGENTS.md §15（开关表）

## 改了什么

- 整包导入 `assets/ReusableDragFx/`（来自 `DragGlowMigration_20261020.zip`）：`DragGlowVisual.ts` / `DragVisualEvents.ts` /
  两个 `.effect` + `.mtl` / 两张 png / 样板预制体与两份说明文档，共 149KB。
- `assets/ReusableDragFx/DragGlowVisual.ts` 打了三处小补丁（其余一字未动）：
  1. `onLoad` 改成「有 `sourceSprite` 才 `prepare()`」；
  2. `onEnable` 在没有 `sourceSprite` 时不报错、不自禁用，且只在有 `sourceTransform` 时挂节点事件；
  3. 新增公开 `bind(sourceSprite, sourceTransform, glowFrame): boolean` —— 运行时把光效临时指到一件道具上。
- 新增 `assets/scripts/gameplay/DragGlowDriver.ts`（挂在 `EffectLayer`）：听 `PIECE_PICK` 就 `bind` + `beginDrag`，
  听 `PIECE_SNAP_SUCCESS` / `PIECE_SNAP_FAIL` / `ORIENTATION_CHANGED` 收尾，听 `GAME_OVER` / `AUTO_PLAY` 直接 `clear`。
- 场景：把样板里的 `DragGlowFx` 挪到 `EffectLayer` 下当静态节点（编辑器里看得见），删掉样板根与 `SampleItem`；
  `EffectLayer` 挂上 `DragGlowDriver`。
- `FeatureFlags` 新增 `dragFx`（默认 `false`，场景里已勾成 **开**）；它一开，`PieceFactory` 不挂 `PieceGlow`、
  `TrailEmitter` 不注册任何监听。

## 为什么这么改

- **一套共享，不是每块一套**：碎片是 `PieceFactory` 现建、`PiecePool` 复用的池化节点，预制体绑定不上；
  按包里的说明「每个道具一套」就得 23 套常驻粒子系统，还随池子反复换父。共享一套只花一个粒子系统，
  且挂在 `EffectLayer` 上不受碎片换父与 `GameLayer` 遮罩影响。
- **否掉「在场景里手工搭一套」**：材质 `uvRect`/`glowColor` 那 4 个 uniform 与粒子 8 个参数在手搭时极易漏，
  直接把包里那棵已经调好的节点搬进来最稳。
- **否掉「让驱动器自己 `instantiate` 预制体」**：AGENTS §3 要求关键视觉节点在编辑器里可见可调；改成静态节点后
  `DragGlowDriver` 连 `@property` 都不用，只按名字找 `DragGlowFx`。
- **补丁只加「晚绑定」这一条路**：原脚本的自检（同图 / Simple+Trim / `packable=false` / 材质 pass / 粒子设为 Custom+Free）
  全部保留，配不上就 `console.error` 并禁用自己，不会静默出怪画面。

## 怎么验的

- 资源导入：`query-asset-info` 七件全 `invalid:false imported:true`（prefab `2d8ed9df…`、两个 effect、两个 mtl、
  `DragGlowVisual` `9a518699…`、`soft-white-dot.png` `be5c579e…`）。
- 编译：`run_script_diagnostics` → `TypeScript diagnostics completed successfully with no errors`。
- 场景：`npm run check`（`verify-scene.js`）只剩改动前就有的几条历史告警；场景文件里能查到
  `DragGlowDriver` 的组件与 `EffectLayer/DragGlowFx` 两个子节点，`sourceSprite/sourceTransform` 已是 `null`（等运行时 bind）。

## 影响什么 / 还没验的部分

- 影响：拖动表现整条换掉；`pieceGlow` / `trail` 两只旧开关在 `dragFx` 开着时不生效（关掉 `dragFx` 就整条退回）。
- **没验**：实机 / 预览里的观感（柔光贴合、光点密度、横屏缩放）、松手后收尾那 0.12 秒、以及 `dragFx` 与
  `stickerPeel` 同时开时的遮挡关系。这些要人眼看着确认。
